# wp-framework-storage

Key-value storage backends for WordPress plugins built on the DWS framework: a small `KeyValueStoreInterface` with in-memory, `wp_options`, and user-meta implementations. Zero internal framework dependencies — a leaf package that `utilities` and consumer plugins build on.

Part of the [DWS WordPress framework](https://github.com/ahegyes/wordpress-framework) — see the monorepo for architecture, contributing, and the rest of the package set.

## Installation

```bash
composer require ahegyes/wp-framework-storage
```
