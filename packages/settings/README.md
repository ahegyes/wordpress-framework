# wp-framework-settings

Declarative settings screens for WordPress plugins built on the DWS framework: storage- and UI-agnostic page/section/field descriptors with a per-field sanitize/validate seam, cross-component field providers, a WordPress options backend, per-entity object fields, and a WP-free render layer. Storage is decoupled from UI — backends reuse the framework's [`wp-framework-storage`](https://github.com/ahegyes/wp-framework-storage) key-value primitives.

Part of the [DWS WordPress framework](https://github.com/ahegyes/wordpress-framework) — see the monorepo for architecture, contributing, and the rest of the package set.

## Installation

```bash
composer require ahegyes/wp-framework-settings
```
